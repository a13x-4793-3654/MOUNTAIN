# 差し込み印刷 テンプレート作成リファレンス

Word（.docx）や Excel（.xlsx）で書式を作るときの「目印（タグ）」の一覧と書き方をまとめたものです。
IT の知識がなくても作れるように書いています。困ったら「よくある質問」を見てください。

---

## 1. これは何ができる機能？

Word や Excel で作った書式（ひな形）の中に、決められた「目印（タグ）」を書いておくと、
MOUNTAIN で契約などを選ぶだけで、**会社名・住所・金額・日付などが自動で埋まった PDF** を作れます。
手で入力する欄（送付理由など）も作れます。

---

## 2. 使い方の流れ（4ステップ）

1. **Word または Excel で書式を作る** … 差し込みたい場所に、この資料の「目印（タグ）」を貼り付けます。
2. **MOUNTAIN に登録する** … 「差し込み印刷」画面で、その Word / Excel ファイルをアップロードします。
3. **契約などを選ぶ** … 「この書式で作成」→ 契約を選ぶと、自動で値が入ります。手入力欄も記入します。
4. **PDF を作る** … 「PDF を作成」を押すと、完成した PDF ができます（作成履歴に残ります）。

---

## 3. 目印（タグ）の書き方

差し込みたい場所に、次の形で書きます（**半角の中括弧 `{ }`** で囲みます）。

````javascript
{MOUNTAIN_見出し_連携_入力の種類_文字数}
```

例）会社名を自動で入れたいとき：

```
{MOUNTAIN_会社名_COMPANY|Name_TEXT_50}
```

### 4つの部品（`_`＝半角アンダースコアで区切ります）

| 部品 | 意味 | 例 |
|---|---|---|
| **見出し** | 入力画面に出る欄の名前。好きな言葉でOK | `会社名`／`宛先`／`送付理由` |
| **連携** | どのデータを自動で入れるか。手入力なら `NONE` | `COMPANY\|Name`／`NONE` |
| **入力の種類** | 目安（文字・数字・日付など） | `TEXT`／`NUM`／`DATE` |
| **文字数** | 最大文字数の目安（数字） | `50`／`100` |

### 大事なルール（これだけ守ればOK）

- 部品の区切りは **半角の `_`（アンダースコア）** です。
- **見出しや各部品の中に `_` `{` `}` を入れない**でください（連携の `|` だけは使えます）。
- タグは **1つのまとまりで書く**。途中で改行（Enter）しないでください。
- 同じタグは、文書の中で **何回でも** 使えます（すべて自動で埋まります）。
- **表の中・ヘッダー・フッターに入れても使えます**。

---

## 4. 自動で入るタグ一覧（コピーして使えます）

「連携」の部分に指定できるものの一覧です。**契約を選ぶと、その契約につながる会社・契約者・口座・金額・担当は自動**で引き当てられます。

### ■ 契約（CONTRACT）

| 入れたい内容 | コピーして使うタグ |
|---|---|
| 契約番号 | `{MOUNTAIN_契約番号_CONTRACT\|ContractNo_TEXT_30}` |
| 管理番号（外部管理番号の主番号） | `{MOUNTAIN_管理番号_CONTRACT\|ManagementNo_TEXT_30}` |
| 契約概要 | `{MOUNTAIN_契約概要_CONTRACT\|Summary_TEXT_100}` |
| 契約区分 | `{MOUNTAIN_契約区分_CONTRACT\|Category_TEXT_20}` |
| 契約状態 | `{MOUNTAIN_契約状態_CONTRACT\|Status_TEXT_20}` |
| 契約開始日 | `{MOUNTAIN_契約開始日_CONTRACT\|StartedAt_DATE_10}` |
| 契約終了日 | `{MOUNTAIN_契約終了日_CONTRACT\|EndedAt_DATE_10}` |
| 契約締結日 | `{MOUNTAIN_契約締結日_CONTRACT\|SignedAt_DATE_10}` |

> **管理番号について**：契約詳細の「外部管理番号」で **主番号（主番号欄が「○」）** に設定した番号が入ります。主番号が無いときは、いちばん最初に登録した番号が入ります。1件も登録が無いときは空欄になります。

### ■ 会社（COMPANY）

| 入れたい内容 | コピーして使うタグ |
|---|---|
| 会社名 | `{MOUNTAIN_会社名_COMPANY\|Name_TEXT_50}` |
| 会社名カナ | `{MOUNTAIN_会社名カナ_COMPANY\|NameKana_KANA_50}` |
| 郵便番号 | `{MOUNTAIN_郵便番号_COMPANY\|PostalCode_ZIP_8}` |
| 都道府県 | `{MOUNTAIN_都道府県_COMPANY\|Prefecture_TEXT_10}` |
| 市区町村 | `{MOUNTAIN_市区町村_COMPANY\|City_TEXT_30}` |
| 住所（番地） | `{MOUNTAIN_番地_COMPANY\|Address1_TEXT_50}` |
| 建物・部屋 | `{MOUNTAIN_建物_COMPANY\|Address2_TEXT_50}` |
| 住所（まとめて） | `{MOUNTAIN_住所_COMPANY\|FullAddress_TEXT_100}` |
| 電話番号（代表） | `{MOUNTAIN_電話番号_COMPANY\|Phone_TEL_20}` |

### ■ 契約者・個人（PERSON）

| 入れたい内容 | コピーして使うタグ |
|---|---|
| 氏名 | `{MOUNTAIN_氏名_PERSON\|FullName_TEXT_30}` |
| 氏名カナ | `{MOUNTAIN_氏名カナ_PERSON\|FullNameKana_KANA_30}` |
| 郵便番号 | `{MOUNTAIN_郵便番号_PERSON\|PostalCode_ZIP_8}` |
| 都道府県 | `{MOUNTAIN_都道府県_PERSON\|Prefecture_TEXT_10}` |
| 市区町村 | `{MOUNTAIN_市区町村_PERSON\|City_TEXT_30}` |
| 住所（番地） | `{MOUNTAIN_番地_PERSON\|Address1_TEXT_50}` |
| 建物・部屋 | `{MOUNTAIN_建物_PERSON\|Address2_TEXT_50}` |
| 住所（まとめて） | `{MOUNTAIN_住所_PERSON\|FullAddress_TEXT_100}` |

### ■ 口座（ACCOUNT）

| 入れたい内容 | コピーして使うタグ |
|---|---|
| 銀行名 | `{MOUNTAIN_銀行名_ACCOUNT\|BankName_TEXT_30}` |
| 支店名 | `{MOUNTAIN_支店名_ACCOUNT\|BranchName_TEXT_30}` |
| 口座番号（下4桁） | `{MOUNTAIN_口座番号_ACCOUNT\|AccountNoMasked_TEXT_10}` |
| 口座名義カナ | `{MOUNTAIN_口座名義_ACCOUNT\|HolderKana_KANA_50}` |

### ■ 金額（AMOUNT）※契約から自動計算

| 入れたい内容 | コピーして使うタグ |
|---|---|
| 残債（未払い残高） | `{MOUNTAIN_残債_AMOUNT\|Balance_NUM_12}` |
| 預り金 | `{MOUNTAIN_預り金_AMOUNT\|Deposit_NUM_12}` |

> 残債＝請求の合計 − 入金の合計（0未満のときは0）。金額は「50,000」のようにカンマ区切りで入ります。

### ■ 担当（ASSIGNEE）

| 入れたい内容 | コピーして使うタグ |
|---|---|
| 担当者名 | `{MOUNTAIN_担当者_ASSIGNEE\|Name_TEXT_20}` |

### ■ 日付（SYSTEM）※PDFを作った日が入ります

| 入れたい内容 | 出る形 | コピーして使うタグ |
|---|---|---|
| 発行日（和暦） | 令和8年7月23日 | `{MOUNTAIN_発信日_SYSTEM\|TodayWareki_TEXT_20}` |
| 発行日（年月日） | 2026年7月23日 | `{MOUNTAIN_発信日_SYSTEM\|TodayJp_TEXT_20}` |
| 発行日（西暦） | 2026-07-23 | `{MOUNTAIN_発信日_SYSTEM\|Today_DATE_10}` |

> 別の日にしたいときは、作成画面でその欄の日付を打ち替えてから「PDF を作成」してください。

## 5. 手で入力する欄の作り方（NONE）

自動データではなく、その都度キーボードで入力したい欄は、連携を **`NONE`** にします。

```
{MOUNTAIN_送付理由_NONE_TEXT_100}
{MOUNTAIN_担当直通番号_NONE_TEL_20}
{MOUNTAIN_備考_NONE_TEXT_300}
```

登録すると、作成画面に **「手入力」** の欄として出てきます。長い文章になりそうな欄は文字数を大きめ（例：`300`）にしておくと親切です。

### 敬称（様・御中）は「手入力」にしてください【重要】

宛名のうしろに **「様」「御中」を直接書かないでください**。宛名（会社名・氏名）が入らなかったときに、**紙に「様」だけが残ってしまう** ためです。

敬称も `NONE`（手入力）のタグにして、**差し込みのとき（作成画面）に入力**します。宛名が無いときは空欄にできるので、「様」だけ残ることを防げます。

```
{MOUNTAIN_氏名_PERSON|FullName_TEXT_30} {MOUNTAIN_敬称_NONE_TEXT_6}
```

「氏名（自動）」のうしろに「敬称（手入力）」を並べておき、作成画面で「様」や「御中」を入力してください（会社宛のときは「御中」、担当者宛のときは「様」など、その文書に合わせて選べます）。

## 6. 「入力の種類」の一覧

| 記号 | 意味 |
|---|---|
| `TEXT` | 文字（制限なし） |
| `NUM` | 数字のみ |
| `KANA` | カナ |
| `DATE` | 日付 |
| `ZIP` | 郵便番号 |
| `TEL` | 電話番号 |

> ※ これは作成画面での「案内（目安）」に使われます。厳密なチェックではないので、迷ったら `TEXT` で大丈夫です。

## 7. レイアウトのコツ

- **書式（フォント・文字サイズ・太字・色・配置）はそのまま活きます**。タグ全体を同じ書式にしておくときれいに出ます。
- 宛名や住所は **表** を使うと整列しやすいです（表の中にタグを入れてOK）。
- 会社ロゴや罫線、ページ番号なども普通の Word 文書と同じように使えます。
- 差出人情報を毎ページに出したいときは **ヘッダー／フッター** にタグを入れられます。
- **敬称（様・御中）はタグに直接書かず、手入力の欄にしてください**（宛名が空のとき「様」だけ残るのを防げます）。→ 詳しくは「5. 手で入力する欄の作り方」。

## 8. よくある質問・困ったとき

**Q. PDF にタグ（`{MOUNTAIN_...}`）がそのまま出てしまった**
→ タグの形が少し違っています。多いのは「区切りの `_` が足りない／全角になっている」「途中で改行した」「`{ }` が全角」です。半角で、4つの部品がそろっているか確認してください。

**Q. 欄が空っぽになる**
→ 選んだ契約にそのデータが無い場合、空欄になります（例：口座が未登録など）。契約側のデータをご確認ください。手入力欄は、作成画面で入力すれば埋まります。

**Q. 宛名が入らず「様」だけ残ってしまう**
→ ひな形に「様」「御中」を直接書いていると起こります。敬称は手入力のタグ（例：`{MOUNTAIN_敬称_NONE_TEXT_6}`）にして、差し込みのときに入力してください。宛名が無いときは敬称も空欄にできます。

**Q. 会社名などを直したい**
→ 作成画面では、自動で入った値も **その場で書き換え** られます。書き換えてから PDF を作成してください。

**Q. あとで作り直したい**
→ 「作成履歴」から「直して作り直す」を選べば、前回の内容を呼び出して作り直せます。日付や手入力の内容もそのまま残っています。

**Q. 同じ人の名前を何か所にも出したい**
→ 同じタグを必要な場所すべてに貼れば、全部同じ値で埋まります。

## 9. コピー用・最短の例

督促状の冒頭部分の例です。そのまま Word に貼って試せます。

```
{MOUNTAIN_発信日_SYSTEM|TodayWareki_TEXT_20}

{MOUNTAIN_会社名_COMPANY|Name_TEXT_50} {MOUNTAIN_敬称_NONE_TEXT_6}
（ご担当：{MOUNTAIN_氏名_PERSON|FullName_TEXT_30} {MOUNTAIN_ご担当敬称_NONE_TEXT_6}）
〒{MOUNTAIN_郵便番号_COMPANY|PostalCode_ZIP_8}
{MOUNTAIN_住所_COMPANY|FullAddress_TEXT_100}

契約番号：{MOUNTAIN_契約番号_CONTRACT|ContractNo_TEXT_30}
ご請求残高：{MOUNTAIN_残債_AMOUNT|Balance_NUM_12} 円

{MOUNTAIN_送付理由_NONE_TEXT_200}

担当：{MOUNTAIN_担当者_ASSIGNEE|Name_TEXT_20}
```

> 別紙「差し込み印刷_サンプルテンプレート.docx」は、すべてのタグを一覧にした Word ファイルです。
> そのまま MOUNTAIN にアップロードして、契約を選ぶと、どの項目がどう入るか一度で確認できます。

> **上の例の「敬称」について**：`{MOUNTAIN_敬称_NONE_TEXT_6}` と `{MOUNTAIN_ご担当敬称_NONE_TEXT_6}` は手入力の欄です。作成画面で「御中」「様」などを入力します。宛名が無いときは空欄にすれば、「様」だけが残りません。

## 10. Excel（.xlsx）で作るとき

Word だけでなく **Excel（.xlsx）** のひな形も同じように使えます。表・請求書・一覧形式の書式は Excel の方が作りやすいことがあります。

### 書き方は Word と同じ

タグの形（`{MOUNTAIN_見出し_連携_入力の種類_文字数}`）と、使えるタグ一覧（4章）は **Word とまったく同じ** です。Excel では、差し込みたい **セルの中にタグをそのまま入力**します。

例）あるセルにこう入力します：

```
{MOUNTAIN_会社名_COMPANY|Name_TEXT_50}
```

- 1 つのセルに、文章とタグを混ぜてもOKです（例：`ご請求額：{MOUNTAIN_残債_AMOUNT|Balance_NUM_12} 円`）。
- 1 つのセルに複数のタグを並べてもOKです。
- **セルを結合**している場合は、いちばん左上のセルにタグを入れてください。
- ヘッダー／フッター（ページ上下の余白部分）にタグを入れても差し込まれます。

### できあがり（PDF）の見た目は Excel の設定どおり

PDF は Excel の **「ページレイアウト」タブの設定（印刷範囲・用紙サイズ・向き・拡大縮小）** のとおりに作られます。ここが Word との一番の違いです。はみ出す・余計な列が出るときは、登録する前に Excel 側で次を設定してください。

- **印刷範囲の設定**：印刷したい範囲を選択 →「ページレイアウト」→「印刷範囲」→「印刷範囲の設定」。
- **1 ページに収める**：「ページレイアウト」→「拡大縮小印刷」を「横 1 ページ／縦 1 ページ」に。
- **用紙の向き**：横長の表なら「印刷の向き」を「横」に。

> ヒント：Excel で「印刷プレビュー」を見て、**紙に出したい形になっていること**を確認してから登録すると失敗がありません。差し込みタグは印刷プレビューでは文字のまま見えますが、MOUNTAIN で PDF を作るときに実際の値へ置き換わります。

### 注意点

- 対応しているのは **新しい形式（.xlsx）** です。古い `.xls` は非対応なので、Excel で「名前を付けて保存」→「.xlsx」で保存し直してください。
- 計算式（SUM など）はそのまま使えます。ただしタグを直接 **計算式の中**には入れないでください（`=` で始まるセルの中のタグは置き換わりません）。金額などは自動タグ（例：残債）を使うか、値のセルに置いてください。
````
